Finding the "UI from hell" game

15:38 Which game it was

You asked me to find a funny web game with a terrible interface, possibly seen on Hacker News, where buttons move out of your way.

Best match: User Inyerface, made by the design firm Bagaar. It reached the Hacker News front page several times (944 points in 2021, 757 in 2019). It's a sign-up form built from every bad web pattern, and it fits "UI from hell" and the Hacker News memory.

What I couldn't confirm: none of the sources I read mention buttons dodging the cursor, so I can't say that detail is from this game.

Runner-up: Hostile Volume, a game about adjusting the volume through deliberately bad controls. It was on Hacker News in March 2026 with 119 points.

Searches that found nothing: "UI from hell" and "UX from hell" on Hacker News, and a general web search for dodging-button games, which only turned up button code libraries.
