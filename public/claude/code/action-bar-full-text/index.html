Action bar buttons show the full text

You asked to see the whole prompt on each quick-reply button. Buttons no longer cut text, and long ones are set to wrap onto more lines. The length limit knob is gone from the Tweaks panel because nothing uses it. The first install was briefly broken by a layout setting the app refuses; a test caught it and it was fixed before any restart.

Untested: how wrapping looks in the real app, because the desktop app draws its own native buttons.
