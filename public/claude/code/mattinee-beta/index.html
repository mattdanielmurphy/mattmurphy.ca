17:06 Auto-building Beta in Applications

You asked for the Mac test build to live in one findable place and build itself.

Where it lives

/Applications/Mattinee Beta.app. The two Mattinee Test copies went to the Trash. mac/local.sh is gone, so no agent makes more copies.

How it stays current

launchd job ca.mattmurphy.mattinee-beta runs mac/beta.sh every 15 seconds. When app/, mac/ or iina-plugin/overlay.html change on master (local, or pushed from elsewhere; origin checked every 5 minutes), it builds what TestFlight would ship from a clean export of master, about a minute. Chosen over a git hook because a hook misses pushes from elsewhere and can't do the wait-until-closed swap.

Open app safety

If Beta is open the build waits in ~/Library/Caches/mattinee-beta.noindex, and goes in within 15 seconds of closing, through one atomic rename. Tested: 1.6 million checks during a swap, none found the app missing.

Own identity

Bundle ID ca.mattmurphy.mattinee.beta, so settings and macOS data are separate from TestFlight. Cost: you pick Who's watching once in Beta, and it asks for the microphone once. Same icon as the real app. Rejected: sharing the ID, because two copies with one ID confuse Spotlight and "open".

Build label

Bottom-right pill in Beta's window (under the player), and a Build line in the app menu of Beta and TestFlight builds.

Extra fix

First run opened the first person's server, Tyler's, which was down, so it showed "Can't reach Mattinee". It now uses the first server that answers. Servers 4801 to 4805 were all down at 17:00; only yours (4806) answered. Not touched; may matter for those people.

Limits

A failed build makes no alert: it shows in mac/beta.sh status and the log, and retries every 30 minutes. Notification via osascript was dropped because the input guard blocks it. Playback wasn't tested in Beta.

Undo

launchctl bootout gui/$(id -u)/ca.mattmurphy.mattinee-beta, remove the plist from ~/Library/LaunchAgents, move the app to Trash.
